Architecture

12 12/12
Transformer beginner
▼
The foundational architecture for all modern LLMs. Uses self-attention to process all tokens in parallel, replacing RNNs.
Transformer = Encoder + Decoder Self-Attention(Q, K, V) = softmax(QK^T / √d_k) · V
encoder-decoderparallelO(n²) attention
Example: All GPT, Claude, Gemini, LLaMA models are decoder-only Transformers
💡 The key insight: attention lets the model weigh relevance of every token against every other token
Related:
Self-Attention Multi-Head Attention Positional Encoding

Multi-Head Attention intermediate
▼
Runs multiple attention operations in parallel, each learning different relationship patterns between tokens.
MultiHead(Q,K,V) = Concat(head_1,...,head_h) · W_O head_i = Attention(QW_i^Q, KW_i^K, VW_i^V)
h=8 to 64 headsd_k = d_model / h
Example: GPT-4 uses ~96-128 attention heads
💡 Different heads learn syntax, semantics, coreference, etc.
Related:
Self-Attention Transformer Flash Attention

Self-Attention beginner
▼
Each token attends to all other tokens in the sequence to compute a context-aware representation.
Attention(Q,K,V) = softmax(QK^T / √d_k) · V Q = queries, K = keys, V = values
O(n²) complexityquadratic memory
Example: Scaled by √d_k to prevent softmax saturation
💡 This is why context windows matter — longer = more compute

Positional Encoding intermediate
▼
Injects sequence order information since Transformers process all tokens simultaneously.
PE(pos,2i) = sin(pos / 10000^(2i/d)) PE(pos,2i+1) = cos(pos / 10000^(2i/d))
sinusoidalRoPEALiBi
Example: RoPE (Rotary) is now standard in most LLMs
💡 Without position info, 'dog bites man' = 'man bites dog'

Layer Normalization advanced
▼
Stabilizes training by normalizing activations across the feature dimension.

Residual Connections intermediate
▼
Skip connections that add input directly to output, enabling gradient flow in deep networks.
output = LayerNorm(x + Sublayer(x)) Pre-LN: output = x + Sublayer(LayerNorm(x))
deep networksgradient flow
Example: Without residuals, models deeper than ~10 layers can't train
💡 Residuals let the model learn identity functions trivially

Mixture of Experts (MoE) advanced
▼
Routes each token to a subset of specialized FFN 'experts', activating only a fraction of parameters.

KV Cache advanced
▼
Caches key-value projections from previous tokens to avoid redundant computation during generation.

Flash Attention advanced
▼
IO-aware exact attention algorithm that reduces memory from O(N²) to O(N) by tiling.

Inference & Sampling

11 11/11
Temperature beginner
▼
Controls randomness in token selection. Lower = more deterministic, higher = more creative.
P(token_i) = exp(logit_i / T) / Σ exp(logit_j / T) T=0: argmax T→∞: uniform
T=0: deterministicT=0.7: balancedT=1.2: creative
Example: For code/math: T=0-0.3. For creative: T=0.7-1.0
💡 Temperature ≠ confidence. It reshapes the probability distribution.
Related:
Top-p (Nucleus Sampling) Top-k Sampling
v1.0 Source: OpenAI

Top-p (Nucleus Sampling) beginner
▼
Samples from the smallest set of tokens whose cumulative probability ≥ p.
Sort tokens by probability descending Keep adding until Σ P(token_i) ≥ p Renormalize and sample
p=0.1: very focusedp=0.9: diversep=1.0: no filtering
Example: Top-p=0.9 means ignore bottom 10% probability mass
💡 Better than Top-k because it adapts to distribution shape
Related:

Top-k Sampling beginner
▼
Samples only from the k most probable tokens, ignoring the rest.
Sort tokens by probability descending Keep top k tokens Renormalize and sample
k=1: greedyk=40: commonk=100: diverse
Example: Fixed k is problematic: sometimes 5 tokens cover 99%, sometimes 1000
💡 Top-p is generally preferred over Top-k

📖 Glossary
Token
The basic unit of text processed by an LLM. Words are split into subword tokens (e.g., 'tokenization' → ['token', 'ization']).
Embedding
A dense vector representation of a token or text that captures semantic meaning.
Context Window
The maximum number of tokens a model can process in a single request.
KV Cache
Key-value cache that stores attention projections to avoid recomputation during generation.
MoE
Mixture of Experts — a architecture where only a subset of parameters are activated per input.
RAG
Retrieval-Augmented Generation — injecting relevant documents into the context before generation.
LoRA
Low-Rank Adaptation — efficient fine-tuning by training small matrices instead of the full model.
RLHF
Reinforcement Learning from Human Feedback — training with human preference data.
DPO
Direct Preference Optimization — simpler alternative to RLHF that skips reward modeling.
CoT
Chain-of-Thought — prompting the model to show reasoning steps before answering.
ReAct
Reasoning + Acting — interleaving thinking steps with tool calls.
MCP
Model Context Protocol — standardized protocol for connecting LLMs to tools.
Temperature
Controls randomness: 0 = deterministic, 1 = balanced, >1 = creative.
Top-p
Nucleus sampling — samples from the smallest set of tokens whose cumulative probability ≥ p.
Transformer
The neural network architecture underlying all modern LLMs, using self-attention.
Attention
Mechanism that allows each token to weigh the relevance of all other tokens.
Fine-Tuning
Training a pre-trained model on specific data to adapt it to a task.
Hallucination
When a model generates factually incorrect or fabricated information.
Prompt Injection
Malicious input that attempts to override system instructions.
Agent
An autonomous system that uses an LLM to plan, reason, and take actions via tools.
Vector Database
A database optimized for storing and querying high-dimensional vectors.
SFT
Supervised Fine-Tuning — training on input-output pairs.
PPO
Proximal Policy Optimization — the RL algorithm used in RLHF.
BPE
Byte Pair Encoding — the most common tokenization algorithm.
Flash Attention
An IO-aware attention algorithm that reduces memory from O(N²) to O(N).
